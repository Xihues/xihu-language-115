# 西湖國小115學年度校內語文學藝競賽

親師生競賽資訊網站，包含競賽時程、年級篩選、參賽須知及級任老師報名入口。

僅限由級任老師填寫表單報名，家長及學生請洽級任老師。同日同地點的項目代表同時舉行。

## GitHub Pages設定

此儲存庫使用靜態HTML，無須安裝依賴或執行建置。

1. 將本目錄的檔案上傳儲存庫根目錄，讓index.html直接位於根目錄。
2. 在儲存庫Settings → Pages，Source選擇Deploy from a branch。
3. Branch選擇main，資料夾選擇/(root)，儲存後等候部署完成。

## 更新報名連結與成績

data.js已填入上、下學期兩份正式Google表單網址及報名截止日。
publishedResults目前保持空白；核定後再填公開得獎名單。完整報名資料與評審成績另由校內承辦環境管理。

## 檔案

- index.html：親師生網頁
- style.css：網頁樣式
- public.js：篩選及內容呈現
- data.js：競賽項目與公開資料
- 115競賽辦法原文.doc：學校提供之原始辦法
- .nojekyll：以靜態檔案直接發布

內容依學校提供的115校內語文學藝競賽實施計畫整理。已依承辦確認內容更新日期、參賽年級與評分方式。書法書寫內容及情境式演說題目由教務處另行提供；台語與客語朗讀教材於網站下載區上架。
